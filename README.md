# Student Management System

A simple and user-friendly web application designed to manage student records efficiently. The project focuses on organised data management, responsive design, and smooth user interactions.

## Features

- Add new student records
- View student information
- Update existing student records
- Delete student records
- User-friendly interface
- Responsive design

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript** – Functionality and user interactions

## Project Structure

```text
Student-Management-System/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Student-Management-System
```

### 3. Run the Application

Open `index.html` in your web browser to use the application.

You can also use the **Live Server** extension in Visual Studio Code for local development.
